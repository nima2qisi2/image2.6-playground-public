# 连续叙事定格动画 · 小红帽定稿版

把故事组织成可见的动作与镜头，保留可复现素材和代码。包内只保留《小红帽 · 门后的影子》22 秒定稿工程；用户换故事时以新故事为准，不把本例的时长、机位数量或人物设为通用要求。

## 复现当前定稿

读取 [复现说明](references/final-case.md)，将 `assets/red-hood-final` 整个复制到可写工作目录，再运行 `film.py`。复现使用已有十二张 PNG，不需要重新生图。保持相对路径和资产文件名。

定稿顺序：潜行入树后 → 戴眼镜 → 穿外婆装靠近 → 敲门与手部近景 → 屋内偷看 → 开门 → 影子先变 → 真身揭晓 → 狼的反应 → 从狼身后仰看巨兽。

## 修改或制作新故事

- 先确定角色行动、观众何时得知信息和反转节拍，再安排机位。保持用户已经确认的角色、服装、构图与材质，只改变要求调整的部分。
- 新近景生成匹配的独立机位；以参考资产约束身份、服装与场景，不用放大全景局部替代新机位。需要本例实际提示词时读取 [新增机位](references/new-shot-prompts.md)、[基础故事](references/story-prompts.txt) 或 [换装前奏](references/intro-prompts.txt)。
- 分层与遮挡参考 [制作细节](references/production.md)。行走检查脚底接地，敲门检查拳头接触，换装安排入遮挡与出遮挡，人物走出后门板必须退到人物后方。
- 影子先变时保留人物原形，再通过中间形态连接巨兽；让帽子、斗篷、发型和位置延续身份。复杂透视和三维形变需要额外素材或其他动画方式，不将二维混合描述为完整三维表演。
- 声音和动作使用同一事件时钟。沿用本例时，`KNOCKS` 同时驱动敲门姿态与拟音。新故事重新安排事件，不只替换画面而沿用旧声音时点。
- 保留母版，再按用途生成缩小 GIF。无损压缩需要比较解码后的像素、每帧时长与循环设置；如果达不到体积目标，如实说明，未经用户同意不降低画质、分辨率或动作帧率。

## 检查与交付

检查步态、接触、门板遮挡、变身中间阶段、反应与剪辑点。完整解码文件，核对尺寸、帧数、累计时长、音轨和循环。连续播放或试听未完成时明确记录，不能用参数检查代替视听验收。

按用户需求交付 MP4、GIF、源资产、实际提示词和检查记录，区分生成、自检与用户验收。生图工具、模型编写代码与编码器的作用分别记录；本例不提供模型间能力对照证据。

本包只包含复现必需的素材、代码与说明，成片及中间帧由运行时生成。发布到外部仓库按当次用户授权范围处理，使用 Skill 不自动授权公开素材。
