# 故事型定格的素材与动作

## 画面与机位

先确定遮挡物、门窗、地面、角色通过区域和反转的尺度。背景、透明角色、近景机位分别生成；各机位须保持建筑位置、材料、光向和角色关系。近景不能靠把全景里的小窗口无限放大。

角色需要正态、换装前后或变身阶段时，沿用同一角色参考与服装层级。生成素材检查实际原生尺寸与 alpha，叠在异色背景检查边缘，不把黑色预览误判为无透明度。

```text
参考作用：{{身份 / 材质 / 服装 / 构图}}
资产类型：{{完整背景 / 近景机位 / 透明角色 / 遮挡层}}
主体保留：{{面部、比例、发型、服装标记}}
材质：{{纤维、层厚、切边、接触阴影}}
空间：{{门窗、地面线、遮挡物、动作接触点}}
拍摄：{{方向、景深、光源}}
阶段：{{原形 / 换装 / 中间形态 / 终态}}
输出：一张完整画幅资产，无网格和文字，{{透明 / 不透明}}。
```

这是创作骨架，不能代替按具体素材编写提示词。

## 分层和接触

- 定位根节点、肩肘腕、髋膝踝、门轴及脚下锚点。蒙版和坐标属于当前原画，不是通用参数。
- 清理原姿态残片后再叠新姿态；关节旋转不能让手指、衣边或鞋底断开。纹理应附着部件，不能滑动或逐帧随机变化。
- 提取材质纹理避开眼嘴、腮红、装饰和阴影轮廓；不把这些图形放大到新肢体上。
- 走路同时控制前进距离、脚步交替和起伏，不能只平移身体。停止后脚步也停止。
- 敲门检查手与门面靠近、接触、退回的连续姿态。门打开后，内部角色先被门板遮挡，走到外侧后层级再切换。

## 隐藏换装

用透明遮挡层和同一场景保持空间连续。先检查目标姿态是否被树干等不透明主体实际盖住；部分穿帮不能被“在树后”这句说明消除。

露出配件只需让动作可辨认，保持在遮挡物边缘，不漂到窗框或远处墙面。角色、衣服与重新出现的形态使用同一套身份和服装参考。前景层可随镜头产生视差，但接入后续镜头时不能突然挡住原构图。

## 变身与反应

锁定身份线索与地面位置，再建立初始、中间和最终形态。身体变大时镜头应为完整轮廓留空间；以角色同框证明体型差，别只靠远近景剪辑。

反应镜头需与已发生的变化对应。小变化先被看到，大变化再揭示，最后给观众读懂反转的停顿。纸偶层的展开和融合不等同完整三维生理变形；必要时生成更合适的阶段，而非把一个姿态任意拉伸。

## 输出检查

保留完整帧序列、实测参数、接触局部和实际编码后的时间点检查。技术检查能证明尺寸、时间、循环和优化一致性，不能证明故事已清楚或画质已被接受。对不可逆动作保留因果顺序，完整故事用重播过渡，不强行来回倒放。
