定稿包含十个镜头，从潜行换装、敲门、屋内偷看到影子先变、真身揭晓和狼的反应；拟音与画面使用同一时间线。MP4 母版为 1600×900、24 fps、22 秒，主要姿态以 12 Hz 更新；GIF 为缩小、无声版本。

## 这个玩法能做什么

- 把故事拆成可拍摄的动作、镜头和节奏，制作纸雕或其他手工材质风格的短片。
- 使用分层素材表现人物移动、遮挡换装、阶段变身和故事反转。
- 为已有故事增加前奏或调整指定镜头，并保留已经确认的内容。
- 复现包内小红帽工程，或依据自己的故事重新制作素材、镜头和动作。

## 怎么使用

### 1. 准备你的想法和素材

可以提供文字故事、角色图片、场景参考或已有视频。尽量说明角色是谁、故事发生在哪里、动作先后、想要的材质风格、画幅与时长；如果有必须保留的人物造型、服装或画面，请明确指出。

只有文字也可以先从分镜开始；制作成片仍需准备相应角色和场景素材。新故事需要重新设计角色分层、动作和镜头，不能保证直接替换示例图片即可完成。

### 2. 安装 Skill

1. 从仓库首页选择 **Code → Download ZIP** 下载仓库并解压。
2. 将 [continuous-stop-motion-gif](skill/continuous-stop-motion-gif/) 整个文件夹复制到项目的 `.agents/skills/` 目录，保留其中的 `SKILL.md`、`assets`、`references` 和 `scripts`。
3. 打开新的 Codex 对话，上传相关素材，并在需求中写上 `$continuous-stop-motion-gif`。

安装 Skill 不会自动安装 Python 依赖或生成动画。[查看完整 Skill](skill/continuous-stop-motion-gif/SKILL.md)

### 3. 用自然语言提出需求

复制下面的示例，替换方括号里的内容：

```text
使用 $continuous-stop-motion-gif，把我的故事制作成剪纸定格风格短片。

故事：［填写人物、场景和事件］
希望表现的动作与反转：［填写］
参考素材的用途：［哪些是角色外观，哪些只是材质或构图参考］
必须保留：［填写角色、服装或已确认的镜头］
画幅和时长：［填写］
输出：先给我分镜和素材方案，确认后再制作预览及 GIF／MP4。
```

想复现这个案例，可以直接说：

```text
使用 $continuous-stop-motion-gif，复现小红帽《门后的影子》定稿动画。
保持十镜头叙事、影子先变和同步拟音，交付 MP4 与 GIF。
```

### 4. 检查并交付

先确认角色和分镜，再检查行走、敲门接触、遮挡换装、开门、变身过渡和剪辑节奏。需要声音时，检查拟音是否与动作对齐；最后实际播放 GIF 和 MP4，并按需要交付素材、提示词及检查记录。

### 直接复现内置案例

按 [定稿工程复现说明](skill/continuous-stop-motion-gif/references/final-case.md)，将整个 `assets/red-hood-final` 复制到独立的可写工作目录。工程使用已有的 12 张 PNG，不需要为复现重新生图。依赖包括 Python、Pillow、NumPy、OpenCV 和 FFmpeg；说明中提供了 Windows PowerShell 的安装和运行命令。

先生成镜头检查图，再导出带声音的 MP4；GIF 需要从母版提取帧并单独编码。脚本会覆盖工作目录的同名输出，修改前应保留副本。

## 使用前请注意

- **检查素材授权。** 使用他人的图片、角色造型、音乐或视频参考前，确认使用许可覆盖公开发布、修改及商业用途；需要时取得授权并按要求署名。
- **说明制作方式。** 本例使用生成图像、分层合成、程序控制和编码制作，是手工材质风格的数字动画。它不是实拍逐帧定格；二维图层混合也不等于完整的三维表演。
- **区分检查与验收。** 定稿工程记录了完整音视频解码与抽帧检查；声音尚未实际试听，不能将技术检查当成听感验收。修改后的作品需要重新检查。
- **留意输出差异。** GIF 无声且受尺寸和色彩限制，不宣称无缝循环；压缩后的画质和体积取决于实际编码设置。
