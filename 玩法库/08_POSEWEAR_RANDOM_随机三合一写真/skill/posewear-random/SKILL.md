# POSEWEAR RANDOM｜随机三合一写真

**任务：** 使用 https://posewear.pages.dev/ 已存在的参考条目，随机得到人物身份、身体姿势与服饰，产生**一张**符合真实商业摄影逻辑的完成写真。禁止只交付文字提示词来代替用户要求的成片。无图像生成能力时如实说明，并输出可执行提示词与抽取记录。

## 识别模式和约束

- SOLO（默认）＝1 人像 + 1 单人姿势 + 1 服装；DUO＝2 不同人像 + 1 **双人**姿势 + 2 套可区分服装。用户明确要求双人时，不得拿单人姿势充数。
- 默认 9:16 竖幅、单张独立生成；用户指定画幅、人数、镜头或复用已有素材时，以用户要求为准。不自动批量生成。
- 仅选明确成年的人物参考。对用户已提供并要求保留的人脸做身份参考；公开样例不擅自声称真人身份。
- 用户说「重新抽」「再来一张」：重抽全部未锁定项。用户仅说「换衣服」「换姿势」「改场景」：只改变指定维度，其余保持。
- **参考成片／单人转双人：** 如果用户直接给出两张成片替换公开案例，描述必须以这些图片为准，禁止将旧抽卡编号和之前的衣服/动作继续写在新案例上。以单人参考图延伸双人时，A 的身份、服装、动作、摄影视角与场景锁定，只加入 B 和明确的双人接触动作；案例见 [单人蹲姿](../../案例/01_单人_绿荫蹲姿.md) 和 [双人环抱](../../案例/02_双人_绿荫环抱.md)。不要将这类用户指定样片伪称为 PoseWear 网站随机结果。
- 每次生成前记录 mode、抽取时间、可见素材池范围、每项 ID／URL／缩略图、固定项、重抽项和实际随机方法。

## 执行次序

1. **确认真实素材。** 访问网站、分辨人像/姿势/服装分类；详读 [references/selection.md](references/selection.md)。只从实际可见/可检索条目随机，不能从网页外观推断任意编号和直接拼造链接；若网站不可访问，转为用户参考或明确的模拟演示，不宣称真随机。
2. **解析主参考。** 对每个抽中的人物提取脸型、发型、气质与成人外观；姿势分解镜头方向、接触点、肩胯轴线、骨盆、腿、膝盖和脚尖；服装分解层次、配色、版型、材质、鞋履、饰品。以动作的实际力学关系约束服装褶皱及遮挡。
3. **双人关系锁定。** 必须记录人物 A/B 的左右位置、对应人脸、服装归属、接触部位、身体重心、视线与前后遮挡。手握手、靠肩、挽臂等双人动作要能在真实摄影中完成。网站没有可核验的双人姿势时，用户允许后方可转为「自定义双人构图」；在抽取报告中标识，而不伪造来源。
4. **自动摄影指导。** 根据两人（或单人）的服装季节、场景可行性和人物气质，选择合理的室内/户外环境。采用 Nikon Z8 / Z9 **摄影风格模拟**、50/85/105 mm 适配焦段、合理的 f/1.8–f/4 景深、真光学散景、自然皮肤。详见 [references/photography-qa.md](references/photography-qa.md)。
5. **生成。** 按 [prompts/solo.md](prompts/solo.md) 或 [prompts/duo.md](prompts/duo.md) 拼接参数；有参考图可附图时，直接将真实三／五项素材作为视觉输入，而非仅靠摘要文字。完整保留姿势主要关节与衣服形状。对单人姿势不强行加大幅度运动。每张独立生图，不把九宫格拆成伪独立作品。
6. **质检与修正。** 对照素材逐项核实人脸、手指、脚、服装材质、人物计数、姿势/互动与衣物接触逻辑；失败则定点修复，不随意修改抽取结果。按“抽取来源 → 场景与参数 → 成片 → 简短质检”顺序交付。

## 不能省略的边界

- **姿势优先于美化。** 不得把站姿生成坐姿、把双手叉腰生成抱手或挽臂；双人挽臂不能变成没有接触的并排站立。
- **参考用途有区别。** 身份看人像，关节角度看姿势，版型/材质看衣服；避免将某张参考自带服装和背景错误继承进合成图。
- **真实像素声明。** “8K细节、尼康相机、85mm”是视觉制作目标而非已验证的真实摄制元数据；实际分辨率如实记录，不能把 1024px 图宣传成原生 8K。
- **版权与来源。** 引用 PoseWear 网站作为参考平台，不在公开仓库打包第三方原图；发布时记录使用来源及需自行核实的授权范围。
- **不要伪造成功。** 若浏览受阻、双人图库不可见、用户未上传输入或图像生成失败，坦白具体限制并给出可继续执行的方案。

## 触发示例

- 「随机来一张写真」→ SOLO 全新抽取、真实单人图。
- 「试一下双人的」→ DUO；两人、一个可核实双人姿势、两套服装。
- 「用刚才这两人，只换冬装」→ 锁定两人和互动姿势，重抽两套冬装。
- 「这张姿势不对」→ 保留其他参考，仅修正姿势关系与机位。

工作完成后，提供编号与链接供用户复查，不把生成意图当作已经验证的素材保真结果。
