# 摄影指导与保真验收

## 视觉优先级

1. 人数、身份匹配与人物位置必须正确。
2. 原姿势骨架、视线、手脚接触点和身体重心必须正确。
3. 服装颜色、材质、版型、层数、裙长及鞋履必须正确。
4. 摄影场景、光线与焦外背景服务穿搭；不能因为背景漂亮就牺牲动作。
5. 最后优化质感与艺术表现，而不是倒过来。

## 景别与参数

- 9:16 竖幅为默认，给头部留空气、鞋底下留地面；全身站姿通常完整显示脚跟与脚尖。双人构图避免一人被边缘截断。
- Nikon Z8/Z9 专业摄影的**模拟风格**；街拍全身可用 50–85mm 视角，人像半身可选 85–105mm 视角。不能把焦段设得过长同时硬塞近景室内且不留摄影距离。
- f/1.8–f/2.8 适合单人半身，双人或全身为保证两张脸和服装主要层次都清楚，可选 f/2.8–f/4。曝光以脸部准确为基准，避免皮肤白片和黑色服装死黑。
- 室外秋装：低角度柔和侧光、树叶暖色散景；春夏：树荫散射日光或清爽海风；正式礼服：现代建筑黄昏或柔光室内；针织/日常：咖啡馆窗边、庭院或街道。场景与服装不匹配时宁可改场景。
- 景深是相机、镜头、人物距离和背景距离共同形成的；不是整张画面套均匀高斯模糊。双人脸部焦平面要尽可能接近，衣服边缘要保持自然过渡。
- 肤质：保留微小肤色差异、毛孔、绒毛、虹膜纹理和发丝；不磨皮、不超锐化、不过分增艳。
- 8K 是目标，不代表原生 7680×4320。报告实际导出像素；需要 8K 时另用明确的高分辨率生成或超分辨率流程，并标注“放大”与“原生”的区别。

## SOLO 质检

- 参考人像是否被错换成姿势图的人脸？年龄感是否成年？
- 是不是完整复刻原姿势的双手、肩膀、腿、头方向和身体重心？
- 鞋子、包、袜子、外套叠穿是否存在？裙摆层数、面料垂坠是否可辨？
- 透视是否可信，手指是否多出/粘连，脖颈/胯部是否畸形？
- 景深是否有正确空间逻辑，主体是否真的清楚？

## DUO 质检

- 画面是否**恰好两人**，A/B 各自清楚，没有交换人脸与服装？
- 两人的动作是否形成参考中要求的**互动**，而非随意并排？
- 相互接触的双手、手肘、肩部、髋部是否连贯，不出现第三只手？
- 是否出现缺腿、鞋只剩一只、黑袜贴成一体、头脸相互叠合？
- 两个人物脸部是否都在可接受的清晰范围，不能只有前景人物清楚。
- 场景光线、身高比例、镜头地平线、阴影方向是否统一？

## 给出验收结果

使用「符合 / 需修正 / 无法核实」逐项标记人数、身份、动作、服装、结构、摄影、像素尺寸。区分“文本描述一致”与“使用原图实际比对成功”。无法访问原始参考图时，不打出“100%还原”。
