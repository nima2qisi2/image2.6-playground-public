# 参考图抽取规范｜真实可溯源、不凭空造卡

## 模式与抽样池

| 模式 | 抽取槽位 |
| --- | --- |
| SOLO | portrait_A / single_pose / outfit_A |
| DUO | portrait_A / portrait_B / duo_pose / outfit_A / outfit_B |

1. 打开 https://posewear.pages.dev/，分别进入人像、姿势、服装模块；记录实际能看到的子类、条目和分页。随机抽取条目之前先确定年龄与内容适合公开写真。
2. **均匀抽样优先。** 能取得完整可用条目时，对符合条件的每张条目等概率抽取；可用 Fisher–Yates 洗牌或安全随机数抽下标。若只能浏览局部分类，则只在该局部做随机抽样，明确“抽样池 = 当前可浏览的 XX 类 / XX 张”，不要写“全库随机”。
3. 相同 ID 不可在同一 DUO 抽为两个身份；同套衣服可以相近风格但不能让 A/B 混穿。对于双人姿势，必须证实该条目包含两人且两人关系明确。
4. 记录 ID、真实落地页 URL、抽取范围、时间（标注时区）、参考图可访问情况。不能根据想象填 URL；如仅有内部编号，则只记录编号和 PoseWear 首页。
5. 多次重抽只重抽用户允许变动的槽位。可保存本轮记录用于重现；来源会更新，复现时先检查链接仍有效。

## 抽取报告模板

- 模式：SOLO / DUO
- 数据来源：PoseWear 网站 / 用户上传参考 / 明确标注的演示模拟
- 抽取时间：
- 可见抽样范围：全库实际可用条目 / 当前页 / 某个分类
- 人像 A：ID、URL、外观特征
- 人像 B（仅 DUO）：ID、URL、外观特征
- 姿势：ID、URL、动作骨架及镜头方向；若为自定义，写“非网站随机姿势”
- 服装 A/B：ID、URL、颜色、廓形、鞋履和配饰
- 随机方法：从可见候选条目抽下标 / 其他可描述的方法
- 不确定项：缺失 URL、图片无法查看、姿势类别不可达等

## 真实性降级

- 来源可访问 + 图像可读取：按实际参考图融合。
- 来源可访问 + 图像无法读取：可记录网页信息，但不声称像素级参考融合；用户要高保真时要求提供图像。
- 双人姿势无法核实：不编造姿势 ID。先找可靠的可访问双人姿势；实在没有时，在用户允许后改用 **自定义双人构图** 并且加粗标注这一事实。
- 来源完全不可访问：只使用用户上传的素材；若用户没提供，输出提示词及“未执行抽卡”的状态，不谎报抽取。
