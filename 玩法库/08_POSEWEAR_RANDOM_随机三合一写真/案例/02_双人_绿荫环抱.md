## 双人动作与角色分配

| 维度 | 从上传图片可见的特征 |
| --- | --- |
| A（前景） | 与单人案例相同外观成年的东亚女性，栗棕色中长层次发、黑色波点细肩带缎面裙、银色项链、黑色细带高跟凉鞋 |
| A 的动作 | 仍保持低位深蹲、双膝收起、双手下垂靠近鞋面，正视镜头微笑 |
| B（后景） | 另一名外观成年的东亚女性，深色盘发与白色花朵发饰、奶油白蕾丝荷叶边短裙、浅色细带凉鞋 |
| B 的动作 | 从 A 后方靠右一侧蹲下，贴近 A 的脸侧微笑，**双臂从后方绕过 A 肩颈和上臂前侧**构成环抱 |
| 视线和关系 | A 看镜头，B 看 A，两张脸距离近但都可辨识；手臂、手指和双人腿部不能融合 |
| 摄影连续性 | 两图同样为石铺地面、右侧柱体、绿叶高亮散景、侧逆光与柔和面部补光 |

## 同一性检查

1. **A 应保持一致：** 脸、发型、黑波点裙、鞋履与深蹲姿势是锁定项。
2. **B 应独立清楚：** 白裙与花饰明显区别于 A，动作确实是身后环抱。
3. **场景连续：** 维持同一石板路、立柱、树叶散景和侧逆光方向。
4. **来源诚实：** 两幅均为用户提供图像，不能把这次替换描述成执行了 PoseWear 随机抽卡或真实尼康拍摄。
