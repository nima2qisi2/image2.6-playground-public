# 横向二十连图

**只有主题时**，直接用内置 image_gen 生图。默认成品为 7280 × 822。先设计左端起点、横贯中段的动作或物体、右端揭晓。例如路飞从左端伸出橡胶手臂，指尖在右端碰到带骨肉。把需要读清的脸、手和食物安排在可见窗口内。生成器若输出较高画布，可在中央横带构图后等比裁去上下留白。若裁切会损伤主体，保护两端并补绘连接段，检查中段纹理、轮廓和接缝后再导出。用户指定的长度若针对某个物体，应从该物体的起止点计量。

**已有原图时**，读取附件原文件的实际尺寸，直接切原像素。保留用户提供的横幅比例；聊天缩略图与 X 截图仅用于判断构图和测量展示间隔。仅在用户明确要求竖幅窄窗时使用 scripts/windows.py 做竖向取景。

**选择切法**：本玩法从主题直接出图时默认用 X 间隔补偿。用户说“间隔补偿”“发 X”时运行下方命令。说“等分”“无缝拼回”时去掉 --x-gap，若两种都要则分别导出至独立目录。

```text
python "<技能目录>/scripts/export.py" "<完整原图>" "<新的主题输出目录>" --x-gap
```

默认可见窗宽与白缝宽取自用户提供的 X 截图，比例为 73 比 16（约 18.25 像素比 4 像素）。若提供了新截图，测量同一行的图宽与缝宽，使用 --window 和 --gap 覆盖，两者采用相同单位。脚本保留左右端点，在 20 个等宽窗口之间跳过 19 段对应内容。白缝只画在模拟预览中。该预览按横幅比例模拟间隔，实际客户端的缩略图裁切、尺寸和圆角需以发布效果为准。

交付时给出 ZIP、切片文件夹和预览链接，告知按 01–20 从左向右排列。检查 ZIP 内图片顺序、数量和每张尺寸。查看补偿预览中的脸部、接触点和跨缝轮廓。若用户要求原图像素直接切片，保留原有切线，即使个别细节落在遮挡区，也不要擅自改图。
