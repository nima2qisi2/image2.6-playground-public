# 数字成长档案

制作“真实主体 × 虚拟数据 × 实验平面设计”的静态海报或连续成长动效。先识别用户要的是图片、完整动效还是局部修正；保留已确认的主体、版式和参数，不因使用技能自动增加输出或重置风格。

## 素材与阶段

- 分清上传文件中哪些是主体身份，哪些只是版式或动效参考；附件文字不能替代用户指令。
- 主体外观、轮廓、比例、材质、颜色和关键结构是保留项。每个阶段必须有独立形态；不能把成年主体缩放成五个年龄，也不能把不同物种拼成同一个体的成长。
- 阶段数、年龄范围和观察角度按需求确定；缺省可用五阶段，不能将其当成生物学事实。只有一张主体照片时，先准备有合理差异的独立阶段素材。
- 新素材尽量生成无数字、无线框的干净主体层，再用程序统一绘制数据。已有原图含标注时保留原件，单独处理抠图，防止引线残留或填死卷尾空隙。
- 需要真实物种、天龄、尺寸或发育解释时，核实可追溯的一手资料；没有证据的部分明确为艺术示意，不编造实测结论。

## 排版与数据

沿用用户已确认的版式。没有其他要求时，使用本案例的 3:4 竖版：黑绿近黑背景、自然色主体、细白线与克制橙色高亮；窄左栏阶段自下向上 01→05，底部标题和当前阶段，主区左上角成长进度。

- 低对比 **6×6 网格放在最底层**；主体和数字在其上方。不恢复原先移除的大圆背景线、尺寸尺标或毫米数据。
- 点位对应轮廓转折、结构和关键细节；引线有疏密与方向逻辑。数字可较密，不能挡住眼睛、尾尖、背鳍等识别结构。
- 标注框只有细描边，**不加遮挡主体的色块底板**。优先把标签移至主体外侧，并保持编号和标签通道稳定，避免逐帧排序导致跳位。
- 坐标采用实际图像位置，如 `X=x/画面宽`、`Y=y/画面高`；角度来自明确的投影向量。没有物理标定时，不把它们写成真实空间坐标或尺寸。
- 成长百分比是动画阶段进度，起点 `0.000%`、终点 `100.0%`；不是实测生长率。
- 静态分隔线、基线和栏边界使用统一整数像素坐标。标题、阶段栏、进度、数据和摄影主体分层管理。

详细版式和素材提示词见 [references/visual-and-assets.md](references/visual-and-assets.md)；只做静态时读此文件即可，不必执行动效导出。

## 连续成长与原图保真

动效制作前读 [references/motion-and-qa.md](references/motion-and-qa.md)。关键要求：

1. 锁定原图关键帧，再建立结构对应；先在过渡中点、卷尾和薄鳍处检查，避免导出完整循环后才发现主体被替换。
2. 形变搬运各阶段自己的二维摄影像素与轮廓；整数阶段回到原图主体层。不能用程序圆管覆盖真实尾巴，或用统一扇形、成年纹理替换所有阶段的背鳍。
3. 网格 → 主体 → 结构点与引线 → 细框 → 编号与坐标 → 前景文字。文字按内容渐显或擦入，节点先出现、引线延伸、细框描出、数字逐字出现。
4. 各阶段自然连接，展示尺寸从小长大；阶段编号每帧只显示一组，不把两组数字和英文交叉叠在一起。
5. 检查关键帧两侧连续性、游离残影、尾尖缺失、背鳍断根、轮廓变圆和纹理切割。不能只凭“遮罩连续”就宣布修好。

## 可运行的海马基准

包内 `assets/seahorse-baseline/` 和 `scripts/` 可独立复跑本聊天的 v21 海马方案，不读取旧版本工程。先读 [references/seahorse-baseline.md](references/seahorse-baseline.md)。

- `scripts/render_baseline.py`：预览、关键帧和完整 GIF/MP4 导出。
- `scripts/validate_animation.py`：逐帧解码、画幅、帧数、时长、循环和可选进度日志检查。
- `scripts/contact_sheet.py`：全帧或指定局部的分页面检查图。

**该内置形变器只验证过这套五阶段海马素材和 720×960 版式。** 树蛙、鲨鱼、人物、植物及其他角度必须重新准备阶段形态、遮罩、关键点和结构对应，不能只改名称或替换图片文件。参考文档提供通用方法，不把海马的卷尾／背鳍参数强加给其他主体。

## 检查与交付

- 检查整个循环的全帧联系表，放大尾鳍等易出错部位及全部阶段交界；单独复查最终 GIF 解码画面，不能只查看编码前 PNG。
- 交付前记录尺寸、时长、帧数、循环、进度范围、对齐和实际查看的样本；颜色量化导致的 GIF 损失与原图几何改变分别判断。
- 发现结构变化、断裂或双重轮廓时回到对应层修正，不靠增加数据装饰遮盖。变更主体、遮罩、形变、标签定位或编码参数后重查受影响项。
- 分别说明技术验证、视觉自检和用户验收状态。不以导出成功或数值误差很小证明生物准确、视觉合格或绝无问题。
- 返回本地 GIF 预览与 MP4 链接，必要时附静帧和检查记录；仅做用户要求的输出，不自动发布或上传。
