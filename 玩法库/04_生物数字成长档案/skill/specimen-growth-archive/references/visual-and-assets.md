# 素材、版式与数据语义

## 准备新主体

先建立阶段表：阶段编号、发育形态差异、镜头朝向、原图路径、来源、已核实事实／艺术假设。重点变化不能仅是画面大小：例如头身比例、肢体形成、尾部吸收或卷曲、骨板、冠棘、鳍膜等要按具体物种处理；这些例子不是各主体通用的发育规律。

对照照片保留主体身份。没有可用阶段素材时，用当前可用的生图能力分阶段生成；本技能不假定某个平台、付费额度或图像模型版本。先统一形态与角度，再做精修。用户指定先看静态时停止于静态交付，后续再接动效。

可替换的干净主体提示词：

> 为【主体／已确认物种】制作【阶段编号与阶段名称】的真实摄影标本图。沿用【身份参考】的颜色、材质、关键识别结构与【观察角度】，本阶段独有形态为【有依据的差异】，与【相邻阶段】形成真实结构变化。主体完整，不裁切尾尖、趾端、触角或薄鳍；黑色背景，真实微距摄影与自然细节。保留【关键结构】的原生轮廓、骨板或表面起伏。此图用于后续程序排版，不生成数字、标注框、UI、尺标或水印。不能以缩小成体、3D 线框、机械替换或过度平滑来表达幼体。

批次先检查所有阶段并排：真实形态差异、同类身份、朝向一致、展示尺寸小→大。保留原图，修正件另存版本。

## 当前海马版式的数值基准

仅用于复刻当前 720×960 案例；其他尺寸按新网格重排，不能将下列坐标当通用标准。

| 项 | 基准 |
| --- | --- |
| 画幅 | 720×960，3:4 |
| 左栏 | 分隔线 x=136，y=60…773；01 在底，05 在顶 |
| 主图网格 | x=154…682，步长 88；y=94…742，步长 108；7 条纵线与 7 条横线构成 6×6 单元 |
| 网格色 | RGB (12,23,23)，主区背景约 (4,13,13) |
| 全宽橙线 | y=774、775，两整行 |
| 底部白基线 | y=920，x=36…684 |
| 成长进度 | 标题约 (158,84)，数值约 (158,99) |
| 字体 | 极细无衬线数据；底部主体英文标题较重 |

保留顶部栏目、小号中英文说明、窄阶段栏、右侧小幅直排学名、底部大标题与单一阶段编号。左栏的数据量不能压过摄影主体；尺寸数据与尺标已被用户删除。

## 坐标、角度与框

- 原点约定为画面左上角；x 向右，y 向下。归一化值在 [0,1] 内，默认显示三位小数。
- 给每个关键点固定 ID，如 P03 始终跟踪吻端，不能为了排版互换 ID。
- `angle = abs(degrees(atan2(y_b-y_a, x_b-x_a)))` 是指定向量相对图像 x 轴的投影角；若要结构夹角，必须另用两向量计算并标明定义。
- 合理的小数与编号可以作为虚拟设计数据，但虚拟值应在案例记录中说明，不能包装成实验测量。
- 标签在主体外侧，以实际文字宽度建立细框；检查框内文字区域与主体遮罩的相交。引线可以穿插，眼睛、尾尖、背鳍等识别结构不被标签盖住。
- 使用抗锯齿绘制动态细线与文字，再统一缩采样；固定基线另用整数像素单一几何源绘制。

黑／灰色矩形不能用来遮住主体或错误。修复底图旧字应只作用于背景层；若直接覆盖遮罩底板，会重现黑块挡住主体的问题。
