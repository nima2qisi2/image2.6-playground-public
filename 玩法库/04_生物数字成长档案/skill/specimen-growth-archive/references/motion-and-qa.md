# 图像形变与复查

## 分层和端点

保存原始图、主体颜色、透明遮罩、结构点、可选的尾／鳍等局部层及 UI。颜色先预乘透明度再重采样，避免黑边。带网格和文字的整张海报不能直接参与摄影主体形变。

每个整数阶段先与其原始主体层核对轮廓和纹理，再检查阶段左右极限。数值小不代表视觉正确：曾经出现“轮廓遮罩连续，但骨板尾巴已变成平滑圆管”的错误。

海马基准的处理：

- 主干由原图对应点建立二维网格映射；卷尾用中心线辅助原像素坐标搬运，原始 alpha 决定真实棘突和骨板外缘。
- 中心线只帮助对应，不负责画出圆管、填补尾体或生成新皮肤。
- 鳍膜与鳍条来自每个阶段自己的摄影像素，根部要与主干对应。不能将成年纹理套在所有阶段的手绘扇形上。
- 关键帧精确返回原始主体数组。连续阶段间使用一致的运动参数，不在每个阶段重新急停、重启。
- 清理游离小影像前确认它确为残留，不能误删真实薄鳍、细尾、触须或透明结构。

对其他主体重新设计结构对应。例如树蛙的肢体出现、尾部吸收，与海马卷尾的映射拓扑不同。姿态或结构差异太大时，应补中间形态或重新登记对应，不把局部硬拉到一起。只提供了静帧时，不声称已完成连续动效。

## 原图带数据时的抠图陷阱

白色引线可能连接两个卷尾边缘；对外轮廓统一填洞会把真实空隙也填成不透明黑色。保留背景连通区域，填补小针孔与已知眼球内部时要局部处理。

白色引线可能变成主体外的小短刺；区分真实有色骨刺与中性细线残留，避免用大尺度腐蚀／平滑把真实轮廓也削掉。原始素材不要覆盖。

## 动效顺序

当前基准为 12 秒、25 fps、300 帧：开场渐入 → 连续成长 → 成熟期短暂停留 → 渐隐后重启。没有倒放缩小的尾段。其他时长与帧率由任务决定。

文字按区块渐显、标题擦入；节点先显，再画引线、框，最后逐字显示编号和坐标。每帧使用最新追踪位置计算值；不要将完成静态整张淡入当成文字数字动效。

阶段编号是离散读数，保持每帧仅一组数字与英文。连续坐标、进度可以平滑变化；阶段编号不需要用两组文字交叉叠化。循环重置发生在主体不可见时，进度在可见成长段内单调。

## 复查项目

| 层 | 必看点 | 失败后的处理 |
| --- | --- | --- |
| 原图保真 | 尾部粗细、骨板与棘突、鳍条数量／走向、眼睛与吻部 | 回到原图像素和遮罩，移除替代结构 |
| 卷尾与其他弯曲细肢 | 切片感、条纹错相、内侧黑缝、尾尖缺失、游离尾体 | 查看原始 alpha、映射坐标连续性、曲率与局部对应 |
| 薄鳍／透明结构 | 双轮廓、漂浮鳍根、鳍膜缺口、重复纹理 | 分层登记原生结构；先对齐根部，再核对边缘与纹理 |
| 标签 | 色块底板、框压主体、标签跳位、P15 压卷尾 | 外移文字通道；稳定 ID；重新测字宽 |
| UI | 两组阶段字叠加、旧字底纹残影、分隔线斜边 | 单组读数；只修背景层；整数像素固定几何 |
| 导出 | 调色板损失、帧时长、循环、遗漏帧 | 重新解码最终 GIF；比较摄影主体区域，而非只比大面积黑背景 |

全帧联系表用来检查整段尺寸趋势、主轮廓与游离影像；另放大局部检查所有阶段中点及交界前后。播放／检查能力存在限制时如实记录，不将缩略图查看写成全尺寸逐帧验收。

交付记录区分：程序断言、人工查看样本、未验证项、用户验收。重复导出不能代替找原因；定位到原图／遮罩／映射／UI／编码层后再修正。
