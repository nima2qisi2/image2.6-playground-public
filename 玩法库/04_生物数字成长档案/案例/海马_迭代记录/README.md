## 观察边界

版本记录反映当时的修改目标，不意味着每个视觉问题已解决。v17–v19 的局部重建曾牺牲原图纹理；v20 才明确核对原图保真，v21 是后续复测。技术检查、制作者自检与用户视觉验收是不同环节，目前未记录最终用户验收。

阶段形态为艺术化重建，坐标、进度和早期尺寸数字是画面示意，不是真实生物测量或发育记录。
