# 深海下潜末帧接龙 Skill

[返回玩法](../../README.md) · [8000m 机舱案例实录](references/deep-sea-8000-case.md)

`deep-sea-descent-chain` 是一套把一次深海下潜做成 60 秒连续感长镜的流程说明：情绪弧与六段深度分段先行，图生视频以末帧接龙完成六段下潜，深度监控 UI 由脚本后期逐帧渲染叠加（不让视频模型画数字），硬拼成精确 60.000 秒。完整流程与验收标准见 [SKILL.md](SKILL.md)。

## 你需要准备

- 一个下潜主题：目标深度（如 5000m、8000m）、视角（机舱第一视角／艇外同向跟拍）、情绪弧走向（如亮→暗→险）、每段想遇到的生物或地貌（每段只定一件）。
- 硬约束逐项想好：画面要不要文字、要不要人物、声音是纯环境声还是静音——这些会逐字写进每段提示词。
- 运行环境：FFmpeg（提末帧、拼接、叠 UI、校验）、Python 3＋Pillow（渲染 UI 帧序列）、可用的图生视频生成能力（单次 10 秒）。不需要 Blender、不需要三维数据。

## 安装

将 `deep-sea-descent-chain` 整个文件夹复制到 Codex 的技能目录，随后在新的会话中使用 `$deep-sea-descent-chain`。文件夹需要保留 `SKILL.md`、`references`、`scripts` 和 `assets` 等结构。

## 包内脚本

- `scripts/extract_last_frame.sh`：提取一段视频的最后一帧，作为下一段的唯一参考图。
- `scripts/concat_exact_60s.sh`：把 6 段 10 秒视频流复制硬拼成精确 60.000s／1440 帧成片。
- `scripts/make_depth_hud.py`：按深度关键点表逐帧渲染深度监控 UI（透明面板帧序列）。换目标深度只改脚本顶部三张表。
- `scripts/overlay_hud.sh`：把 UI 帧序列叠到成片右侧，并把音轨截回精确 60 秒。
- `scripts/verify_frames.sh`：三种模式——final（成片规格＋音量＋接点抽帧）、gate（单段五帧构图验收门）、ui（UI 读数核对抽帧）。

脚本依赖 FFmpeg 与 Pillow，均已在 8000m 案例的真实文件上实测通过。

## 你可以这样说

```text
使用 $deep-sea-descent-chain，做一个深海下潜 60 秒视频。
目标深度：［如 8000m］；视角：［机舱第一视角／艇外跟拍］。
情绪弧：［如 明亮愉快 → 逐渐阴暗危险］。
每段事件：［六段各一件，如 珊瑚海龟／水母／巨影／巨型乌贼／未知巨兽／海沟抵底］。
约束：［如 无中文、无人物、无配音，纯环境声］。
深度 UI 要带单位 m 并按段计速，成片精确 60.000 秒，交付时如实列偏差清单。
```

`assets/example-stills/` 里有一张定版案例的舱内代表帧（第 1 段 5s，椭圆舷窗＋海龟＋舱体俱全），可作机舱构图锁的参照。案例技术与视觉自检不代表用户已验收；定版状态见案例页。
