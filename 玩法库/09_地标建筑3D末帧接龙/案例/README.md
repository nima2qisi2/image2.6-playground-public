## 两条路线对比

| | 大阪城（数据路线） | 故宫太和殿（建模路线） |
| --- | --- | --- |
| 几何来源 | PLATEAU 网格 52350422 的 bldg＋cons 数据 | 无可用数据，按公开规制尺寸程序化建模 |
| 主体实测 | 天守高 53.2m，LOD2 共 209 面，无纹理、法线近似上色 | 面阔 63.96m／台基 8.13m／通高 35.05m，两源核对 |
| 静止画 | 东南机位，天守＋石垣＋公园（树为装饰球体、非数据） | 东南机位 (78,−142,68)→(0,0,24)，中和/保和殿剪影陪衬，3 轮试渲定稿 |
| 结果 | 精确 30.000s；接点无跳帧；五层结构未增生 | 精确 30.000s；接点无跳帧；台基三层/屋顶两层未增生 |
| 已知偏差 | 第3段后半全景缓漂；第2段有一拍通道内向镜头 | 第1段环绕非严格正环、落点地理为视频模型自创；大吻被发挥成整条金龙 |

两个案例的视频段均为 AI 生成：远景地理与局部细节有模型发挥，与实景的出入已在各自案例页点名，不能把成片当作实拍或测绘成果。制作全流程实录见 [大阪城实录](../skill/landmark-3d-chain/references/osaka-castle-case.md) 与 [太和殿实录](../skill/landmark-3d-chain/references/taihedian-case.md)。
