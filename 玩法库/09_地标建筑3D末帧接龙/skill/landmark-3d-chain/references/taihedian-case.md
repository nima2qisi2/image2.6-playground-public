# 案例实录｜故宫太和殿（程序化建模路线）

2026-11-23 完成，工程分两步：2026-11-07 先做数据源调研（结论：无匿名可用的精细数据），用户拍板后按规制程序化建模。成片、静止画与建模脚本见 [案例目录](../../../案例/故宫太和殿_程序化建模版/README.md)。

## 第一步：数据源调研（为什么走建模路线）

中国没有 PLATEAU 式开放 CityGML，故宫博物院不提供古建模型下载（「全景故宫」是 360° 照片）。逐个实测的结论：

| 来源 | 内容 | 卡点 |
| --- | --- | --- |
| Sketchfab — Naffis Tang 整组故宫模型 | 167,309 面，CC-BY 4.0 | 下载 API 无账号 token 返回 401 |
| Sketchfab — TRNKL 太和殿屋顶 | 334 万面写实，仅屋顶一层 | 同上 401；且无殿身台基 |
| CGTrader 免费三大殿模型 | 太和/中和/保和＋三层台基 | 需免费账号走下载流程 |
| 3D Warehouse / Printables / MakerWorld | 各有单体或局部模型 | 均需平台账号；Printables 许可证最严 |
| GitHub — world-architecture-atlas-3d 的 forbidden-city.glb | MIT，**唯一匿名可下载** | 仅 244 面/428 点，实测渲染为红盒子＋平板黄盖，**不可辨认，弃用** |
| OSM 轮廓挤出 | 轮廓齐全 | 只有平顶盒子，无庑殿顶与三层台基，不可作主体 |

结论：精细模型都卡在平台账号登录，按规则不绕过。用户选择路线 2——在 Blender 里按太和殿真实规制程序化建模。

## 第二步：规制尺寸（两源核对）

来源：中文维基「太和殿」条目与 visitbeijing.com.cn 故宫宫殿页，数字一致（2026-11-07 检索）。

| 项目 | 数值 |
| --- | --- |
| 面阔 | 11 间，**63.96 m** |
| 进深 | 5 间，**37 m** |
| 殿身高 | **26.92 m** |
| 三层汉白玉台基高 | **8.13 m** |
| 通高 | **35.05 m** |
| 屋顶 | 重檐庑殿顶，正脊大吻高 **3.40 m** |

未核实、建模按近似处理：台基每层高度分配（取等分 2.71m/层）、屋檐举折曲线、斗拱层数与出挑、柱网间距（72 柱）、栏杆雕刻。

## 第三步：建模清单（脚本按米制比例，原点＝太和殿中心，地面 z=0）

1. **三层台基**：82×57 / 76×51 / 70×45 m 逐层内收，白石色；顶层四周简化栏杆（望柱＋栏板，间距 3.4m）；南面中央每层 4 级台阶。
2. **殿身**：63.96×37 m 红墙体（z 8.13→16.6m），南立面 10 条深色柱线分 11 间＋11 块金色门窗色块，北面同门窗、东西山墙各 4 扇窗色块；檐下深色带 0.9m。
3. **下檐庑殿顶**：檐口 71×44m、出挑约 3m，黄色琉璃瓦色；上层红墙带 47×17m。
4. **上檐庑殿顶**：檐口 55×25m；正脊＋两端大吻简化色块至 35.05m。屋面为直坡截锥面，檐角以 3.2m 小斜板（22°）近似上翘。
5. **陪衬**：北侧中轴线中和殿/保和殿简化剪影；南侧太和门剪影（最终机位下在画外）；殿前灰白石广场大平面。广场不加树。

建模脚本即案例目录里的 `assets/build_taihedian.py`，管线与大阪城相同：Blender 4.2.9 便携版无头、Cycles CPU、1280×720、64 samples＋去噪，每帧约 2.2–2.6 分钟。

## 第四步：三轮试渲修正

| 轮 | 机位 | 问题与修正 |
| --- | --- | --- |
| R1 | (70,−130,75)→(0,0,25)，40mm | 结构齐全但整体发白：屋顶柠檬黄、台基三层糊成一块、檐角翘板过大、中央斜坡板渲染成带黑缝浮板。→ 全面加深材质、翘角缩至 3.2m/22°、删斜坡板、台基加压边条分层、天空压暗 |
| R2 | (78,−142,68)→(0,0,24)，40mm | 压边条渲染成三道纯黑粗带，更糟。→ 撤压边条，改三层台基逐层提亮的色阶区分（0.78/0.85/0.92）；屋顶黄加深加饱和；地面与环境光再压暗 |
| R3 定稿 | 同 R2 | 黑带消失；三层台基靠色阶＋真实阶梯阴影分明；红墙 11 间比例正确；重檐两层分明、大吻可见。**验收通过：三层白台基＋红墙＋黄色重檐庑殿顶第一眼可辨** |

## 第五步：三段视频与落点

照大阪城链法：3×10s、只传末帧、硬拼精确 30.000s/720 帧。

| 段 | 运镜 | 抽帧验证 |
| --- | --- | --- |
| 1 环绕 | 以静止画为首帧环绕太和殿 | 0s 为静止画原帧，写实化后环绕带贴顶掠过；末帧落点为金水桥＋大殿正面（视频模型自创地理，**非严格东南→东→北→西→南正环**） |
| 2 穿门登台 | 只喂第1段末帧：过桥推近 → 台阶登临 → 穿正门门洞 → 贴檐上升 → 正脊大吻特写 | 主链到位；登台被压缩为一段台阶＋门洞、非逐层三层；大吻被渲染成整条金龙雕塑（视频模型发挥）；广场有少量远景游客背影 |
| 3 空中俯瞰 | 只喂第2段末帧：从大吻后拉爬升到中轴线高空全景 | 约 7.5s 到位：护城河＋红墙黄瓦建筑群＋北京天际线；宫城地理为理想化拼贴，与实景方位不完全一致 |

两个接点（9.9/10.1s、19.9/20.1s）抽帧构图几乎一致、无跳帧；主殿台基三层与重檐两层全程未增生。

## 近似与偏差总清单（如实）

- 规制尺寸为已核实真值；细部均为建模级近似：屋面直坡无举折曲线、无斗拱、柱网为贴面柱线＋门窗纯色块、大吻为简化色块、无脊兽宝顶。
- 台基平面为规整长方形，非真实土字形平面；每层等分未核实；栏杆无龙头螭首；台阶为简化块、无御路石雕。
- 中和殿真实为圆形攒尖顶，此处按庑殿顶剪影近似；太和门剪影已建但在最终机位画外；午门、金水桥、筒子河未建；广场为无纹理色块平面。
- 视频段偏差见上表（环绕非正环、大吻金龙化、地理理想化拼贴）。
