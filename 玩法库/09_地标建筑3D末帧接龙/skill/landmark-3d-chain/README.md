# 地标建筑 3D 末帧接龙 Skill

[返回玩法](../../README.md) · [大阪城案例](../../案例/大阪城_PLATEAU数据版/README.md) · [太和殿案例](../../案例/故宫太和殿_程序化建模版/README.md)

`landmark-3d-chain` 是一套把地标建筑做成 30 秒航拍感短片的流程说明：真实三维几何在 Blender 里出静止画，图生视频以末帧接龙完成环绕、穿门上升、空中俯瞰三段，硬拼成精确 30.000 秒。完整流程与验收标准见 [SKILL.md](SKILL.md)。

## 你需要准备

- 一座想做的地标建筑，以及它的标志性识别三件套（静止画验收按这个查）、第2段要穿的门、第3段全景要收进的周边地标。
- 如走平台模型路线（Sketchfab、CGTrader 等）：你自己的平台账号——下载需要登录时由你下载后把模型文件交给 Agent，不要让 Agent 绕过登录。
- 运行环境：Blender 4.2 LTS 便携版（Agent 侧免安装解压即可）、FFmpeg（提末帧、拼接、校验）、可用的图生视频生成能力（单次 10 秒）。无 GPU 时 Blender 用 Cycles CPU 出图，1280×720 约 2 分钟/帧。

## 安装

将 `landmark-3d-chain` 整个文件夹复制到 Codex 的技能目录，随后在新的会话中使用 `$landmark-3d-chain`。文件夹需要保留 `SKILL.md`、`references`、`scripts` 和 `assets` 等结构。安装技能不会自动安装 Blender 或生成模型。

## 包内脚本

- `scripts/extract_last_frame.sh`：提取一段视频的最后一帧，作为下一段的唯一参考图。
- `scripts/concat_exact_30s.sh`：把 3 段 10 秒视频硬拼成精确 30.000s／720 帧成片。
- `scripts/verify_frames.sh`：ffprobe 实测规格，并抽出两个接点前后的帧供人工对比。

三个脚本都只依赖 FFmpeg，均已在两个案例的真实文件上实测通过。

## 你可以这样说

```text
使用 $landmark-3d-chain，做一个地标建筑 30 秒末帧接龙视频。
建筑：［名称］；城市：［城市］；识别三件套：［三件套］。
第2段穿的门：［门名］；第3段全景要收进：［周边地标］。
先出 Blender 静止画给我验收，通过后再接三段视频，
成片精确 30.000 秒，交付时如实列偏差清单。
```

`assets/example-stills/` 里有两张已通过验收闸门的静止画（大阪城、太和殿），可作“可辨认”标准的参照。案例技术与视觉自检不代表用户已验收；各案例状态见案例页。
